خط الاستمارة والشهادة
=====================
لتكون الأسماء والأرقام المكتوبة تلقائيًا بنفس خط التصميم تمامًا، ضع ملف الخط هنا باسم:
    vdoc-font.ttf
(الخط العريض Bold — الأقرب لتصميمكم غالبًا Cairo أو Tajawal، وكلاهما مجاني من fonts.google.com).
بعدها ارفع مجلد web كما هو؛ لا تعديل آخر مطلوب. إن لم يوجد الملف يستخدم البرنامج خط الجهاز.
