جمعية الخير للجميع — مشروع Android السحابي الإصدار 7.3

المحتويات:
- app/: تطبيق Android يفتح واجهة النظام من ملفات www المضمنة.
- www/: نسخة الواجهة المطابقة للاختبار على المتصفح.
- database_schema.sql: مخطط قاعدة البيانات المستخدم في النسخة السابقة.
- jkh_cloud/web/: واجهة النشر على الاستضافة، مع إعدادات Supabase.

التحديثات في 7.3:
1) سجل متابعة يدعم الزيارة والمكالمة والبحث الاجتماعي، ونتيجة المتابعة وموعدها القادم.
2) سجل المساعدات يتضمن النوع والمبلغ والتاريخ والمسؤول والملاحظات.
3) مستندات لكل حالة عبر Supabase Storage (حد الملف 10MB).
4) بحث بالاسم والرقم القومي ورقم الحالة والهاتف.
5) تقرير شهري للمساعدات مع إجمالي المبالغ وعددها، وعدّاد للحالات التي تحتاج متابعة/عاجلة/تحت الدراسة، مع طباعة.
6) تحديث يدوي من قاعدة البيانات المشتركة، وحفظ مركزي عبر app_state.
7) تنزيل نسخة JSON واستعادتها إلى قاعدة البيانات السحابية.

البناء:
- افتح مجلد jkh_apk_project في Android Studio.
- انتظر Gradle Sync ثم Build > Build APK(s).
- ملف APK التجريبي يظهر عادةً في app/build/outputs/apk/debug/app-debug.apk.

الاختبارات: فحص صياغة JavaScript باستخدام Node.js نجح. لم يُبنَ APK داخل بيئة الإعداد هذه ولم يُختبر على جهاز Android.

تنبيه أمني مهم قبل إدخال بيانات حقيقية: المخطط الحالي نموذج أولي يستخدم صلاحيات واسعة ومخزن مستندات عام. لا تحفظوا صور بطاقات الرقم القومي أو المستندات الحساسة قبل تشديد RLS، وجعل التخزين خاصًا واستخدام روابط موقعة، وتطبيق صلاحيات دخول موثوقة. مفتاح Supabase المنشور داخل config.js مفتاح عميل عام فقط؛ لا تضعوا Service Role Key هنا.


الإصدار 10: إخفاء بيانات الدخول الافتراضية من شاشة البداية، وإضافة حذف الحالة مع تأكيد وحفظ التغيير سحابيًا.


الإصدار 12: تمت إضافة قسم حملة الواتساب وقسم نشاط الزيارات (دار أيتام، مستشفى 57357، زيارة ترفيهية، زيارة خارجية). تُحفظ السجلات ضمن payload في app_state. أزرار واتساب تفتح wa.me برسالة جاهزة قابلة للتعديل قبل الإرسال.
