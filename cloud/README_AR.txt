جمعية الخير للجميع — الإصدار 6 السحابي

الفكرة:
الموبايل والكمبيوتر يتصلان بقاعدة بيانات سحابية عبر الإنترنت.
لا يلزم أن يكون الجهازان على نفس Wi‑Fi.

المكونات:
- web/index.html: الواجهة الكاملة.
- web/config.js: تضع فيه رابط Supabase والمفتاح العام anon.
- supabase/schema.sql: إنشاء قاعدة البيانات والتخزين والدخول التجريبي.
- android/: مشروع Android جاهز لفتح نسخة الويب السحابية.

خطوات التشغيل:
1) أنشئ مشروعًا جديدًا في Supabase.
2) افتح SQL Editor والصق supabase/schema.sql ثم Run.
3) من Project Settings > API انسخ Project URL و anon public key.
4) افتح web/config.js وضع القيمتين مكان YOUR-PROJECT و YOUR_SUPABASE_ANON_KEY.
5) ارفع مجلد web إلى استضافة ويب HTTPS، أو شغله محليًا للاختبار.
6) افتح الرابط من الكمبيوتر أو الموبايل؛ كلاهما سيستخدم نفس البيانات.
7) الدخول التجريبي: admin / 1234.

مهم:
هذه الحزمة "جاهزة للربط السحابي" وليست حساب Supabase مستضافًا بالفعل، لأن إنشاء الحساب وربطه يحتاج بيانات مشروع الجمعية.
لا تضع Service Role Key داخل config.js.
قبل إدخال بيانات حقيقية، شدّد سياسات RLS وانقل تسجيل الدخول إلى Supabase Auth.

APK:
مجلد android هو مشروع Android، وليس APK مبنيًا. بعد وضع رابط الموقع السحابي يمكن بناء APK من Android Studio.

ملاحظة مهمة للإصدار 7.1:
- تم تحسين شاشة الدخول لتعرض سبب خطأ الاتصال الحقيقي بدل رسالة عامة.
- يوجد زر "اختبار الاتصال السحابي" في شاشة الدخول.
- يجب فتح web/index.html من النسخة الجديدة بعد فك الضغط، وليس من نسخة قديمة.
- يفضّل أن يكون الكمبيوتر متصلًا بالإنترنت أثناء الاختبار.


الإصدار 10: أضيف سجل محاضر مجلس الإدارة لرفع PDF إلى Supabase Storage، وترويسة طباعة تتضمن شعار الجمعية بحجم 5×5 سم واسم الجمعية ومكانها ورقم الإشهار. يلزم التأكد من صلاحيات Storage قبل رفع محاضر فعلية.


الإصدار 10: إخفاء بيانات الدخول الافتراضية من شاشة البداية، وإضافة حذف الحالة مع تأكيد وحفظ التغيير سحابيًا.


الإصدار 12: تمت إضافة قسم حملة الواتساب وقسم نشاط الزيارات (دار أيتام، مستشفى 57357، زيارة ترفيهية، زيارة خارجية). تُحفظ السجلات ضمن payload في app_state. أزرار واتساب تفتح wa.me برسالة جاهزة قابلة للتعديل قبل الإرسال.


مراجعة تطويرية مبنية على ملفات الإصدار 12 المرفوعة:
- إضافة بوابة تسجيل ومتابعة للحالات من شاشة الدخول.
- حقول الزوج والزوجة والأرقام القومية والهواتف، وحالة الملف وسبب القرار.
- عرض قائمة مختصرة للطلبات التي تحتاج مراجعة على الرئيسية.
- مزامنة ملفات الواجهة المحدثة مع نسخة الويب وملفات واجهة APK.
- تم فحص صياغة JavaScript باستخدام Node.js بنجاح.
تنبيه قبل الاستخدام الفعلي: بوابة التسجيل تعتمد على صلاحيات app_state وStorage الحالية في المخطط، وهي واسعة وغير مناسبة لبيانات شخصية حساسة. لا تنشر البوابة للعامة ولا ترفع بطاقات قومية فعلية قبل تطبيق تسجيل دخول آمن وسياسات RLS وتخزين خاص وروابط موقعة. لم يتم بناء APK في هذه البيئة ولم يتم اختبار الاتصال الفعلي بمشروع Supabase.
