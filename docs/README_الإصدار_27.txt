الإصدار 27:
1) تسجيل التبرعات: نموذج جديد يختار المتبرع من قائمة المتبرعين (بحث بالاسم/الهاتف) أو تكتب اسمًا جديدًا فيُضاف تلقائيًا لقائمة المتبرعين. يحفظ رقم المتبرع مع التبرع. زر «حفظ + إرسال الإيصال واتساب».
2) المتبرعون: زر «واتساب» لكل متبرع، و«رسالة واتساب للمعروضين» (يحترم البحث)، و«استيراد الأسماء من الهاتف».
3) الإيصالات (وسجل التبرعات): زر «إرسال واتساب» يفتح محادثة المتبرع بنص الإيصال، مع «مشاركة كصورة» و«تنزيل الصورة».
4) حملة الواتساب: إنشاء حملات بأسماء وحذفها (مع مشاركيها)، وإعادة تسميتها، والتصفية بالحملة، والإرسال لمشاركي حملة. استيراد الأسماء من: جهات اتصال الهاتف، ملف (vcf/csv/xlsx)، جروب/مجموعة واتساب (ملف «تصدير المحادثة» .txt أو لصق قائمة الأعضاء). الأرقام المكررة تُستبعد.
5) الحالات: قائمة «فرز التكرار» (أي تكرار / الاسم / الرقم القومي / العنوان / رقم الهاتف / أكثر من نوع) مع ملصقات توضح نوع التكرار لكل حالة وملخص بالأعداد، وتجميع المتكررات بجوار بعضها.
6) «طلبات بانتظار ردّكم»: أضيفت علامة ✕ لإغلاق الصندوق، ويعود فقط عند وصول طلب جديد.
7) إعادة تحميل الصفحة: لم يعد يخرج لشاشة الدخول؛ تُستعاد الجلسة والصفحة المفتوحة وتُحدَّث بياناتها (الجلسة تنتهي بإغلاق التبويب أو بعد 30 دقيقة خمول أو بالخروج).
8) تطبيق الأندرويد: إذن قراءة جهات الاتصال (READ_CONTACTS) وجسر للاستيراد من الهاتف، وفتح روابط واتساب في التطبيق. يلزم إعادة بناء APK. (لم يُبنَ ولم يُختبر على جهاز.)
لا يحتاج أي تعديل على قاعدة البيانات.
