الإصدار 16:
1) تجاوب تلقائي كامل: موبايل / تابلت / كمبيوتر / شاشات العرض الكبيرة (تكبير تلقائي).
2) تنقل هرمي: الرئيسية ← القسم ← الفرع، مع مسار تنقل (Breadcrumb) وزر رجوع.
   زر الرجوع (المتصفح أو الأندرويد) يرجع داخل البرنامج فقط ولا يخرج منه.
3) أقسام الجمعية التسعة كاملة، وأضيف ما كان ناقصًا: البحث الاجتماعي، المتبرعون، إيصالات الاستلام،
   خطة المساعدات، المخازن (وارد/صرف/جرد/رصيد/صلاحية)، الموظفون والحضور والمهام، المصروفات،
   الخزنة والبنوك، المشروعات ونسب الإنجاز، التقرير المالي، سجل العمليات، وأدوار جديدة (إدارة، مسؤول مخازن).
الملف المعدّل: jkh_cloud/web/index.html (ونفسه داخل jkh_apk_project/app/src/main/assets/www/).
البيانات الجديدة تُحفظ داخل app_state (حقل extra) فلا حاجة لتعديل قاعدة Supabase.
لم يتم بناء APK ولم تُختبر الواجهة على أجهزة فعلية في هذه البيئة.

الإصدار 16.1: ترويسة الموبايل مختصرة (المزامنة والنسخ والساعة والإشعارات تحت سهم صغير)، زر القائمة ☰ عائم لا يشغل مكانًا، أيقونات الأقسام اثنتان بجانب بعض دائمًا، وأحدث الحالات منظمة وقابلة للفتح والغلق.
