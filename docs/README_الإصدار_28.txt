الإصدار 28: طابور إرسال واتساب تلقائي (اختياري، مطفأ افتراضيًا)
1) كل أزرار «إرسال واتساب» (الإيصالات، المتبرعون، الحملات، الحالات) صارت تمر على دالة واحدة. عند تفعيل الطابور تُضاف الرسالة لجدول wa_queue بدل فتح wa.me؛ وإن فشلت الإضافة يُفتح واتساب يدويًا كما كان.
2) في «مركز رسائل الواتساب» زر جديد «إضافة الكل للطابور» لإرسال حملة كاملة دفعة واحدة (حتى 500 رسالة).
3) مجلد jkh_wa_server: خادم Node صغير (Baileys) بشريحة منفصلة، حد يومي، فواصل عشوائية، نافذة إرسال، وقائمة منع ("إيقاف"). شغّل README_AR.txt داخله.
4) شاشة «طابور الإرسال التلقائي» داخل صفحة «حملة الواتساب» (تظهر فقط عند تفعيل JKH_WA_QUEUE): حالة الخادم (متصل / واتساب غير متصل / متوقف)، عدد المنتظر والمُرسل اليوم مقابل الحد والفاشل، وآخر 40 رسالة، مع أزرار: إلغاء رسالة، إعادة محاولة الفاشلة، وإلغاء كل المنتظر (للمدير فقط). تتحدث تلقائيًا كل 20 ثانية.
خطوات التفعيل بالترتيب:
  أ) Supabase > SQL Editor: شغّل jkh_cloud/supabase/wa_queue.sql  (لا يمس بقية الجداول)
  ب) شغّل الخادم وامسح QR بالشريحة المخصصة، وجرّب رسالة واحدة لرقمك.
  ج) في config.js غيّر window.JKH_WA_QUEUE إلى true وارفع الواجهة. (تطبيق الأندرويد يحتاج إعادة بناء APK.)
لم يُختبر: تشغيل SQL على Supabase، والاتصال الفعلي بواتساب، وبناء APK. اختُبر: صياغة الواجهة ومسارات waLink ومنطق الطابور في وضع المحاكاة.
